# Shepot

Push-to-Talk голосовой ввод текста для Windows x64 на языке D (`ldc2`) и Win32 API.

## Возможности
- **Движки распознавания:** `whisper.cpp` (Vulkan GPU / CPU) и `sherpa-onnx` (CPU). Встроенные пресеты (`GigaAM v4 RNN-T`, `GigaAM Multilingual CTC`, `Whisper tiny`–`large-v3-turbo`) скачивают нужные DLL и веса автоматически; любую локальную модель `.bin` / `.onnx` можно выбрать через **«Обзор...»**.
- **Ввод текста:**
  - `sendinput` — посимвольный ввод с настраиваемой задержкой в настройках (для игр).
  - `clipboard` — вставка через `Ctrl+V` (по умолчанию не затирает картинки и файлы в буфере).
  - `auto` — посимвольно до 80 символов, длиннее через буфер обмена.
- **Управление:** удержание или Toggle-режим, глобальная клавиша/кнопка мыши, отмена по `Esc`, иконка в трее, плавающий HUD-индикатор, автовыгрузка модели при простое, `replacements.json`, интерфейс `EN / RU` и проверка обновлений на GitHub.
- **Без мусора рядом с exe:** одиночный и установленный `shepot.exe` хранят `config.json`, `replacements.json`, `models/` и DLL в `%LOCALAPPDATA%\Shepot` (если рядом с exe уже лежат `config.json`/DLL или файл-маркер `portable`, автоматически работает portable-режим).

## Сборка (Windows x64)
Требуются **LDC2** (`dub`) и линковщик **MSVC**:

```powershell
dub test --compiler=ldc2
dub build --compiler=ldc2 --build=release
.\bin\shepot.exe
```

## Флаги командной строки
- `--setup` — проверить/скачать DLL и выбранную модель и выйти.
- `--check` — проверить загрузку модели и микрофон и выйти.
- `--no-download` — запретить автоскачивание файлов.
- `--wav=<путь>` — распознать WAV-файл (16 kHz mono PCM) и вывести результат в консоль.
