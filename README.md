# Shepot

Нативная Push-to-Talk диктовка для Windows на языке **D (LDC2)** + **Win32 API** + **whisper.cpp** (Vulkan GPU / CPU).

## Возможности
- **Без тяжёлых рантеймов:** нативный Win32 GUI + системный трей (без Electron, WebView2, Python или .NET).
- **Vulkan GPU и CPU:** ускорение на видеокартах AMD / NVIDIA / Intel через Vulkan или переключение в режим **«Только на процессоре (CPU)»** прямо из интерфейса.
- **Умное управление видеопамятью (VRAM):**
  - автоматическая выгрузка модели из VRAM при простое (`1` / `3` / `5` / `10` / `15` / `30` минут или `Никогда`);
  - ручная загрузка/выгрузка одной кнопкой;
  - если модель выгружена, запись в RAM при нажатии кнопки стартует мгновенно, параллельно идёт загрузка модели с мягким секундным щелчком и звуком активации по готовности.
- **Гибкий Push-to-Talk:** назначение на любую клавишу клавиатуры или боковую/среднюю кнопку мыши (`MOUSE3`, `MOUSE4`, `MOUSE5`) с подавлением стандартного действия в браузерах и Discord.
- **Плавающий HUD-индикатор и иконка в трее:** не забирает фокус у активного окна, цветом показывает запись (красный), обработку с процентами (оранжевый) и вставку (зелёный). Поддерживает опциональный **Live-предпросмотр речи** в HUD во время диктовки.
- **Мягкие звуковые сигналы:** синтезированные в памяти тихие синусоидальные сигналы через `PlaySoundW`.
- **Автоустановка зависимостей:** при первом запуске автоматически скачивает `whisper.dll` (`Whisper.net.Runtime.Vulkan`) и выбранную модель `ggml-*.bin` с HuggingFace.

## Сборка из исходников (Windows x64)
Требуется **LDC2** (с `dub`) и линковщик **MSVC** (Visual Studio Build Tools; `rc.exe` не нужен — ресурс `assets/app.res` уже предсобран):

```powershell
dub test --compiler=ldc2
dub build --compiler=ldc2 --build=release
.\bin\shepot.exe
```

При первом запуске недостающие DLL и модель скачаются автоматически (либо можно заранее вызвать `.\bin\shepot.exe --setup`).

## Флаги командной строки
- `--setup` — проверить/скачать `whisper.dll` и модель, затем выйти.
- `--check` — проверить загрузку модели, прогрев и захват микрофона, затем выйти.
- `--no-download` — запретить автоматическое скачивание недостающих файлов.

## Основные файлы
- `source/app.d` — координация потоков, таймаут VRAM, live-предпросмотр.
- `source/audio.d` — захват микрофона (16 кГц, моно, `f32`) через `winmm` без GC-аллокаций в коллбэке.
- `source/stt.d` / `source/whisper_c.d` — динамическая загрузка `whisper.dll`, фильтр тишины и галлюцинаций.
- `source/os_win.d` — Win32-окно, трей, контекстное меню, глобальные хуки клавиатуры/мыши, HUD-оверлей, буфер обмена/`SendInput`, автозапуск в реестре.
- `source/sound.d` — генерация мягких WAV-сигналов в памяти.
- `source/bootstrap.d` — автозагрузка Vulkan DLL и моделей через `curl.exe` и `tar.exe`.
- `source/config.d` — чтение и сохранение `bin/config.json`.
